# Organic Chemistry Mastery

A responsive, GitHub Pages-ready starter platform for learning organic chemistry.

## Features included
- Professional responsive dashboard with chemistry-inspired visual identity
- 22 curriculum modules and a searchable topic directory
- Guided lesson template with simple explanation, scientific definition, worked examples, steps, common mistakes, and exam point
- Selected worked lessons for organic chemistry, carbon, isomerism types, sp³ hybridization, Markovnikov's rule, and SN1
- English, Urdu, and Roman Urdu selector (translation coverage is currently limited to selected core topics)
- Interactive quiz with score and explanatory feedback
- Molecular formula mass calculator for supported simple formula syntax
- Functional-group quick finder and simple reaction/name practice
- Topic bookmarks, completion progress, and personal notes stored in browser localStorage
- Dark mode and mobile navigation

## Publish on GitHub Pages
1. Create a GitHub repository, for example `organic-chemistry-mastery`.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL it provides.

No build system or package installation is required.

## Important scope and accuracy note
This is a functional front-end starter, not a complete peer-reviewed digital textbook. It includes all 22 requested module categories and many topic links, but only selected core topics have fully written lesson content in this version. Other topic pages provide a study framework. The formula calculator supports simple element-count formulas only; it is not a chemical database. The IUPAC practice is limited to a few examples and is not a general structure-to-name engine. 3D molecular rotation, true chemical drawing, full mechanism animation, spectrum datasets, cloud accounts, and a complete scientifically reviewed question bank require additional components/data and are not falsely represented as implemented.

For coursework, check advanced mechanisms, reaction conditions, spectra, stereochemical assignments, and nomenclature against an authoritative textbook or instructor.
